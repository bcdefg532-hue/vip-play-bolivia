# VIP PLAY BOLIVIA 🎮

Plataforma profesional de juegos y recompensas con sistema VIP, minijuegos, misiones y sorteos.

## 🎯 Características Principales

✅ **Sistema de Usuarios**
- Registro e inicio de sesión
- Recuperación de contraseña
- Perfil de usuario con estadísticas
- Guardado automático de progreso

✅ **Sistema VIP**
- VIP 1 (10 Bs → 110 Diamantes)
- VIP 2 (20 Bs → 220 Diamantes)
- VIP 3 (50 Bs → 570 Diamantes)
- VIP ELITE (100 Bs → 1166 Diamantes)

✅ **Sistema de Pagos**
- Generación de QR dinámico
- Carga de comprobante de pago
- Estados de pago (Pendiente, Verificado, Activado)
- Panel de administración para aprobar pagos

✅ **Minijuegos**
- 🚗 Carrera de Autos
- ⚽ Penales de Fútbol
- 🧠 Juego de Memoria
- 🏃 Runner Infinito
- 🎯 Tiro al Blanco

✅ **Sistema de Misiones**
- Jugar partidas
- Ganar partidas
- Completar niveles
- Iniciar sesión diariamente
- Conseguir puntuaciones específicas
- Invitar amigos

✅ **Sistema de Sorteos**
- Sorteos semanales y mensuales
- Sistema de boletos (según nivel VIP)
- Historial de ganadores
- Premios: Diamantes, VIP Gratis, Recompensas especiales

✅ **Funcionalidades Extra**
- 🏆 Ranking semanal
- 🎁 Cofre diario
- ⭐ Sistema de logros
- 👥 Sistema de referidos
- 📊 Panel de administración
- 🔔 Notificaciones en tiempo real

## 🎨 Diseño

## 🚀 Inicio Rápido

1. **Clonar el repositorio**
```bash
git clone https://github.com/bcdefg532-hue/vip-play-bolivia.git
```

2. **Abrir en el navegador**
```bash
open index.html
```

3. **O usar un servidor local**
```bash
python -m http.server 8000
# Luego acceder a http://localhost:8000
```

## 💾 Datos Almacenados

La aplicación utiliza `localStorage` para guardar:
- Usuarios y contraseñas
- Progreso del jugador
- Diamantes y puntos
- Misiones completadas
- Pagos pendientes
- Reclamos
- Logros
- Referidos

## 🎮 Cómo Jugar

1. **Registrarse** con correo y contraseña
2. **Comprar un VIP** mediante pago
3. **Jugar minijuegos** para ganar puntos
4. **Completar misiones** para avanzar
5. **Participar en sorteos** con tus boletos
6. **Reclamar recompensas** al completar el nivel
